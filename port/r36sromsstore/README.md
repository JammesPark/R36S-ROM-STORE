# R36S ROM HUB STORE

**Status:** versão 0.7.0-beta — beta oficial.

Loja independente para R36S/R36H. Baseado no R36S PORT HUB, por Lag do Lira (https://youtube.com/@lagdolira), com créditos aos temas originais. Código sob GPL-3.0, conforme LICENSE e NOTICE.md.

Extraia o pacote de instalação em ports e execute R36S ROMS STORE.sh com runtime LÖVE 11.5 disponível. A loja usa o diretório r36sromsstore e mantém suas configurações separadas. O catálogo próprio é sincronizado pela rede e conserva a última cópia válida no SD. Atualizações pelo canal oficial: https://github.com/JammesPark/R36S-ROMS-HUB-STORE-UPDATES/releases.

A instalação e atualização devem preservar os dados do usuário; faça backup antes de atualizar. Use apenas conteúdo cuja distribuição e download estejam autorizados.

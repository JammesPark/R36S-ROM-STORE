# R36S ROM STORE

**Status:** versão 0.7.1-beta — candidata oficial em revisão privada.

Loja independente para R36S/R36H. Baseado no R36S PORT HUB, por Lag do Lira (https://youtube.com/@lagdolira), com créditos aos temas originais. Código sob GPL-3.0, conforme LICENSE e NOTICE.md.

Extraia o pacote de instalação em ports e execute R36S ROM STORE.sh com runtime LÖVE 11.5 disponível. A loja usa o diretório r36sromstore e mantém suas configurações separadas. O catálogo próprio é sincronizado pela rede e conserva a última cópia válida no SD. Canal de atualizações: https://github.com/JammesPark/R36S-ROM-STORE-UPDATES (canal OTA da nova pasta).

A instalação e atualização devem preservar os dados do usuário; faça backup antes de atualizar. Use apenas conteúdo cuja distribuição e download estejam autorizados.

Matrix é o tema principal nas novas instalações. Pulse continua disponível. As imagens cover.png, fanart.png e logo.png são geradas no build com a marca aprovada. Para usar a fonte original em resolução nativa, coloque logo_hd.png nesta pasta antes de compilar. A identidade interna de salvamento LÖVE é preservada.

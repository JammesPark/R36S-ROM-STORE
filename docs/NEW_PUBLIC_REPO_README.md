# R36S ROMS STORE — Atualizações públicas

Repositório **exclusivo** de atualizações do aplicativo R36S ROMS STORE para consoles portáteis.

- Feed de atualização: `update.json`
- Releases: versões `roms-vX.Y.Z-beta` com instalador, pacote UPDATE e código-fonte.
- Todos os pacotes são verificados por SHA-256 antes de serem anunciados no feed.
- A loja consulta o feed automaticamente, mas só instala com confirmação.
- Projeto distribuído sob GNU GPL-3.0; código-fonte incluído em cada Release.

**O repositório não contém ROMs nem BIOS de terceiros.** Não reutiliza o canal de outros aplicativos.
